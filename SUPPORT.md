# Support Policy

Thank you for using SaaSKit! This document outlines how you can get help and support for the project.

## 1. Documentation & Resources

Before reaching out, check our documentation to see if your question is already answered:
- **Architecture & Design:** Refer to our [Architecture Specification](docs/architecture.md) and ADRs in [docs/adr/](docs/adr/).
- **Implementation Roadmap:** Look at [docs/implmentation.md](docs/implmentation.md) to understand current status and future milestones.
- **Reference Config:** Inspect the commented [.env.example](.env.example) file for all server settings.

## 2. Community Channels

For general help, discussions, and community interactions, use the following:
* **GitHub Discussions:** Use [SaaSKit Discussions](https://github.com/medaminerjb/saas-kit/discussions) for Q&A, architectural debates, and sharing how you use the project.
* **GitHub Issues:** Open an issue if you've found a bug or want to request a feature. Make sure to use the templates!
* **Community Slack/Discord:** Join our chat servers to connect with other developers using SaaSKit. (Links will be updated on the main page).

## 3. Commercial Support

If you need enterprise SLA support, migration assistance, or custom integration services, please contact:
* **Email:** **support@saaskit.dev**
* **Website:** [https://saaskit.dev/support](https://saaskit.dev/support)

## 4. Reporting Bugs

If you encounter an issue that you believe is a bug:
1. Search active and closed GitHub issues to see if it has been reported or resolved.
2. If it hasn't been reported, open a new issue using the **Bug Report** template.
3. Provide a minimal reproducible example (code, configurations, or steps) to help us resolve the issue quickly.
